- Every `cachedXxxLines + xxxCacheKey` pair in `AppState` must be cleared **together**; adding a new panel cache also requires adding both fields to the selection-change reset block in `render()` (app.ts ~line 695). Clearing only the lines (or only the key) silently shows stale panel content after session navigation — no error, just wrong data.
- `prevFrame = []` is required whenever a full-screen render mode is entered or exited (e.g. `resolutionActive` transitions). `flushFrame` in `render.js` diffs against `prevFrame`; if the previous frame was built by a structurally different render path (different panel composition), the diff emits corrupt ANSI sequences with no error.
